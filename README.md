# 미적분 수학개념 도슨트

2026학년도 2학년 2학기 미적분 구술 수행평가 운영 도구입니다. 교사가 웹을 켜 두고 학생 1명씩 평가하며, 결과는 Google Sheet에 저장됩니다.

## 평가 흐름

1. 첫 화면에서 차수를 고릅니다. 현재는 1차만 열려 있고, 2차는 "2차는 준비중입니다." 안내를 띄웁니다.
2. 교사용 PIN으로 로그인하고 반·학생을 선택합니다.
3. 학생이 상·중·하 또는 자신이 준비한 문제를 고르면, 해당 난이도에서 문제 1개가 무작위로 뽑히고 4분 타이머가 시작됩니다.
4. 설명하지 못하면 같은 난이도에서 처음 문제를 뺀 나머지 중 한 번 다시 뽑을 수 있습니다. 타이머는 새로 시작되고 해결 시 3점이 차감됩니다.
5. 결과(해결·미해결·미시도)를 고르고 평가 완료를 누르면 Sheet에 한 번 저장되고 점수가 표시됩니다.

## 채점 기준 (차수별 50점 만점, 기본점수 30점)

| 상황 | 점수 |
| --- | --- |
| 상 처음 문제 해결 | 50 |
| 상 다시 뽑아 해결 · 중 처음 문제 해결 | 47 |
| 중 다시 뽑아 해결 · 하 처음 문제 해결 | 44 |
| 하 다시 뽑아 해결 · 자신이 준비한 문제 해결 | 41 |
| 시도했으나 해결하지 못함 | 38 |
| 시도하지 않음 | 30 |

미참여자 점수(최하점 −1)는 앱에서 기록하지 않으며 성적 처리 때 별도로 부여합니다. 점수는 서버에서 다시 계산해 저장합니다.

## Google Sheet 구성

- `학생명렬`: 명렬 xlsx에서 읽은 학생. 비고에 자퇴·전출·휴학이 있으면 `활성`이 FALSE이며 평가 대상에서 빠집니다.
- `문항목록`: 차수·난이도별 문항 (`src/lib/question-bank.ts`에서 생성)
- `1차_평가기록`: 학생별 고정 1행, revision으로 다중 기기 동시 저장 충돌 검사
- `평가이력`: 생성·수정·강제 덮어쓰기·초기화된 모든 저장본
- `점수현황`, `점수통계`: 수식으로 계산되는 학생별 점수와 반별 통계
- `설정`: 제한 시간(`durationSeconds`, 기본 240초)과 경고 시간

## 환경 변수

`.env.example`을 참고해 `.env.local`을 만들고, 같은 값을 Vercel Production 환경에도 등록합니다. 대상 Sheet에는 서비스 계정 이메일을 편집자로 공유해야 합니다.

## Sheet 초기화

```powershell
npm install
npm run setup:sheet -- --check --roster "C:\경로\2026학년도 2학년 2학기 명렬.xlsx"
npm run setup:sheet -- --roster "C:\경로\2026학년도 2학년 2학기 명렬.xlsx"
```

`--check`는 Sheet에 연결하지 않고 명렬과 문항 수만 확인합니다. 다시 실행해도 기존 평가 기록은 학번 기준으로 유지되며, 기록이 있는 학생이 명렬에서 빠지면 중단합니다. 학생 이름은 Git에 저장하지 않습니다.

## 2차 평가 열기

1. `src/lib/question-bank.ts`에 `round: 2` 문항을 추가합니다.
2. `src/lib/rounds.ts`에서 2차의 `open`을 `true`로 바꿉니다.
3. `npm run setup:sheet -- --roster ...`를 다시 실행해 `2차_평가기록` 탭과 문항을 만듭니다. 점수현황·점수통계는 현재 1차 기준이라 2차 합산 열은 이때 함께 추가해야 합니다.
